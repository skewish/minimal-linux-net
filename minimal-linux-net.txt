minimal-linux-net

1. my parent system pre-build setup (fyi)

-64-bit debian linux on /dev/sda1 (newest release) default installation
-compiler installed (see also minimal-linux-new text)
-previously built minimal-linux-new (ex. on /dev/sda8)
-internet connection

2. within the parent system (debian) open a terminal and become superuser

~# su -

3. mount the partition where minimal-linux-new exists

~# mount -t ext4 /dev/sda8 /mnt/sda8

4. download & unpack the following source code into /mnt/sda8/tmp

https://ftp.gnu.org/software/inetutils/ (newest release) --> /mnt/sda8/tmp
https://sourceforge.net/projects/net-tools/ (newest release) --> /mnt/sda8/tmp

unpack files, remove archives & chown to root
~# chown -R 0:0 /mnt/sda8/tmp

5. compile & install inetutils

cd /mnt/sda8/tmp/inetutils*/
./configure --prefix=/usr
make
make DESTDIR=/mnt/sda8 install

6. compile & install net-tools

cd /mnt/sda8/tmp/net-tools*/
make config
make
make DESTDIR=/mnt/sda8 install

7. add /mnt/sda8/etc/hostname

~# cat > /mnt/sda8/etc/hostname << 'done'
localhost
done

8. add /mnt/sda8/etc/hosts

~# cat > /mnt/sda8/etc/hosts << 'done'
127.0.0.1 localhost
done

9. add /mnt/sda8/etc/nsswitch.conf

~# cat > /mnt/sda8/etc/nsswitch.conf << 'done'
hosts: files dns
done

10. add /mnt/sda8/etc/protocols

~# cat > /mnt/sda8/etc/protocols << 'done'
icmp 1 ICMP
done

11. add /mnt/sda8/etc/resolv.conf

~# cat > /mnt/sda8/etc/resolv.conf << 'done'
nameserver 1.1.1.1 1.0.0.1
done

12. obtain default route information for your system

~# ip route show (sample output information shown)

	default via 192.168.0.1 dev eno1 proto dhcp src 192.168.0.254 metric 100
	192.168.0.0/24 dev eno1 proto kernel scope link src 192.168.0.254 metric 100

13. create a script called "net0up" (use your output information)

~# cat > /mnt/sda8/sbin/net0up << 'done'
#!/bin/sh
ifconfig eno1 192.168.0.254 netmask 255.255.255.0 up
route add default gw 192.168.0.1
done
~# chmod 0755 /mnt/sda8/sbin/net0up

14. create a script called "net0dn"

~# cat > /mnt/sda8/sbin/net0dn << 'done'
#!/bin/sh
ifconfig eno1 down
done
~# chmod 0755 /mnt/sda8/sbin/net0dn

15. reboot (at grub menu select minimal-linux-new)

16. plug in an ethernet cable (if not already present)

17. check if eno1 is renamed & update net0up and net0dn as needed

~# ifconfig -l

	eth0 lo sit0 (this shows eno1 is now named eth0, use ed to update)

18. test the network connection

~# /sbin/net0up (connects the network)
~# ping 8.8.8.8 or ping yahoo.com (use Ctrl-c to stop), or
~# telnet horizons.jpl.nasa.gov 6775
~# /sbin/net0dn (disconnects the network)
